How to Publish 100% Free

Host under your own custom name without paying a single cent

Option 1: Host on Vercel or Netlify (Easiest)

  1. Save this file as index.html on your computer.
  2. Create a free account on GitHub.com and create a repository named unscroll-app.
  3. Upload your index.html file to the repository.
  4. Go to Vercel.com or Netlify.com, log in with GitHub, and select "Import Repository".
  5. Click **Deploy**! In 10 seconds, your app will be live at a custom URL like yourname-unscroll.vercel.app for 100% free forever.

Option 2: Host Directly on GitHub Pages

  1. In your GitHub repository settings, scroll down to the **Pages** section.
  2. Select the main branch as source and click **Save**.
  3. Your site will be live at username.github.io/unscroll-app!

How Users Install It on Phone (No App Store Needed)

Once your link is live:

  • iPhone (Safari): Open the link → Tap the **Share** button → Tap **"Add to Home Screen"**.
  • Android (Chrome): Open the link → Tap the **Three Dots** menu → Tap **"Install App"** or **"Add to Home Screen"**.
